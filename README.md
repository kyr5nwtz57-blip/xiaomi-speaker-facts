# 小爱音箱豆包实时语音平台

> 让小米音箱说上豆包全双工实时语音，同时保留官方小爱

为小米音箱接入豆包端到端实时语音（火山引擎 Seeduplex 全双工）。唤醒、打断、退出只由命中词触发，进入会话后一切交给豆包语音自主发挥，不在代码里写死任何话术；同时保留官方小爱，可随时切回。以安装器形式交付：新机器克隆仓库 + 拉取 Release 资产 + 填入个人密钥，即可复现整套安装。

API / 开发者服务 · 智能音箱实时语音方案 · 2026 年
